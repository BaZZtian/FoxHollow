# FoxHollow

Dedicated native PS5 port project for Star Fox Adventures. Target firmware: 12.40.
Requires the user's own GameCube disc image. No original game files are included.

There is currently no playable PS5 build or downloadable application release.

Native foundation: [Foxhollow](https://github.com/JackPriceBurns/foxhollow),
revision `55371a2354ef36d4aabe53dfb78c19aa7f493737`. Upstream authors retain
their applicable rights and notices. The existing [MIT license](LICENSE)
covers the independently authored tooling already licensed under it, not
Nintendo's game data or every upstream dependency.
